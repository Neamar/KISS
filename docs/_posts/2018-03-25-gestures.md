Gestures require minimalistic mode: turn it on from `⋮, KISS settings, Home screen, Minimalistic UI`. Gesture settings are disabled until you do.

## Supported gestures
KISS currently supports five gestures:

* Swiping up
* Swiping down
* Swiping left
* Swiping right
* Long press

## Where to use gestures
Simply swipe up/down/left/right or long press on the large wallpaper (red rectangle):

![Gestures on minimalistic mode in KISS](/screenshots/gestures-minimalistic.png)

Note that a bonus gesture can be supported if you enable `⋮, KISS settings, Home screen, Show history when touching the home screen`: in this case, simply touching (not swiping) the wallpaper will display the history.

## Gestures configuration
By default, the following actions are configured over the gesture area described above:

* Scroll up to display the keyboard (start touch event on wallpaper and finish touch event on wallpaper)
* Scroll down to display notifications
* Scroll left or right to display the apps
* Long press to display the apps

You can configure the action to run for these gestures from `⋮, KISS settings, Gestures`: there is one `Action on swipe ...` setting per direction, and `Action on long press`.

Available actions are:

* Do nothing
* Display keyboard (default for up)
* Hide keyboard
* Display notification shade (default for down)
* Display quick settings
* Display apps list (default for left, right and long press)
* Display history
* Display menu
* Go to homescreen (opens your default launcher, or resets KISS when KISS is your launcher)
* Launch…, to open any app, contact or shortcut of your choice (pick it with the `Item to launch` setting appearing below)

## Double tap to lock
> This will only work for Android Pie and above.

You can enable double tap to lock from `⋮, KISS settings, Gestures, Double tap to lock screen`.

Like other gestures, this requires minimalistic mode and only works over an empty area of the home screen.

The first time you do a double tap, a permission dialog will appear, make sure to enable KISS.

## Disable gestures
From `⋮, KISS settings, Gestures, Action on swipe up`, you can select "Do nothing" as an action. Do the same thing for the other `Action on swipe ...` settings and `Action on long press` to totally disable gestures.
